# Customer Churn & Retention Analysis

## Project Overview

This project analyzes customer churn and retention patterns using the IBM Telco Customer Churn dataset.

The objective is to identify customer characteristics and service-related factors associated with customer churn and generate actionable business insights using Python, statistics, and data visualization.

## Objectives

- Analyze the overall customer churn rate
- Compare churned and retained customers
- Analyze customer tenure and monthly charges
- Analyze churn across contract types
- Analyze churn across internet service types
- Analyze churn across payment methods
- Perform statistical tests
- Generate business insights for customer retention

## Dataset

The dataset used in this project is the IBM Telco Customer Churn dataset.

- **Rows:** 7,043
- **Columns:** 21
- **Target Variable:** Churn

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Churn rate analysis
- Tenure analysis
- Monthly charges analysis
- Contract analysis
- Internet service analysis
- Payment method analysis
- T-test
- Chi-square test
- Data visualization

## Key Insights

- Overall customer churn rate was approximately **26.58%**.
- Churned customers had substantially lower average tenure than retained customers.
- Churned customers had higher average monthly charges.
- Month-to-month customers had the highest churn rate.
- Fiber optic customers showed a relatively high churn rate.
- Electronic check customers had the highest churn rate among payment methods.

## Conclusion

The analysis identified important customer and service-related patterns associated with churn. These insights can help businesses identify higher-risk customer groups and develop targeted customer retention strategies.
